# FAO Global Production 2026.1.0 compared with the current API

The current API (`docs/`) is built from `data/fishstat_export_s_capture2020.csv`, a FishStatJ export covering 1950 to 2018. This report compares it with the legacy-format files built from the FAO Global Production 2026.1.0 release (1950 to 2024), over the years both cover.

To reproduce:

    Rscript _bin/download_fao_data.R 2026.1.0
    Rscript _bin/build_landings_api_data.R data/fao/GlobalProduction_2026.1.0.zip /tmp/build2026
    Rscript _bin/compare_landings.R docs /tmp/build2026

## Summary

- **Global totals agree.** Over 1950 to 2018 the totals differ by 0.01%, and no single year differs by more than 0.14%. The new pipeline reproduces the existing numbers; the differences are FAO revisions.
- **Former USSR.** FAO now reports 1988 to 1991 catch under the USSR (`SUN`) rather than its successor states, so Russia, Ukraine, the Baltic states, Georgia and others lose catch in those years and `SUN` gains it. Figures for 1987 and earlier are identical.
- **New countries.** Guernsey (`GGY`) and Jersey (`JEY`) are reported separately. Svalbard and Jan Mayen (`SJM`) has no catch in either build, so it has no file in the new one.
- **Sardines.** FAO has merged the regional *Sardinops* pilchards into *Sardinops sagax* (`CHP`, now named "Pacific sardine"). The codes `JAP` (Japanese pilchard), `CPI` (California pilchard) and `PIA` (Southern African pilchard) are gone, and `CHP` gains about 120 million tonnes over 1950 to 2018.
- **Anchovy.** Most Southern African anchovy (`ANC`) catch is now reported as European anchovy (`ANE`).
- **Other species codes.** 20 species codes from the current API have no catch in the new release, and 597 codes are new. Many other species have small revisions.
- **Dropped rows.** As before, rows for entities with no ISO 3166 alpha-3 code (former Ethiopia PDR, former Sudan, and "Other nei") are left out: about 7.8 million tonnes over 1950 to 2024.

## What this means for the legacy URLs

If the legacy URLs switch to the 2026 data, some species files (for example `/landings/species/JAP.json`) would no longer be regenerated, and their figures now sit under other codes. Whether to keep serving those files, and with which data, is part of the step 4 decision on legacy URLs in `TASKS.md`.
