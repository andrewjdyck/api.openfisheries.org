## 1. Fix known bugs

- [x] Subsidies filter bug in `_bin/subsidies.R`: the loop variable `iso3c` masked the column, so `filter(iso3c == iso3c)` kept every row and all 152 per-country files in `docs/subsidies/` were identical. Fixed by renaming the loop variable, and regenerated the files. Each file now holds only its own country's rows (1,980 rows in total, matching the input). The totals files are unchanged. The functions now live in `_bin/subsidies_utils.R`, and the `X1`/`...1` readr column-name difference is handled.
- [x] Pipeline used global variables (`out_data`, `country_list`, and others) and hardcoded years. Refactored into functions with explicit inputs and outputs. The year range now defaults to every year in the export and can be overridden. Choosing a subset of years now pairs each year with its own symbol (`S`) column, which the old code got wrong for subsets. The output folder is a parameter and defaults to `docs/`; the old script wrote to `./api/`.
- [x] `build_landings_api_data.R` called `output_global_json` twice and had the cleanup step commented out. Tidied up: the duplicate call is gone, and cleanup is an opt-in `clean = TRUE` argument that removes only the per-country and per-species folders (the old version deleted the whole `landings/` folder).
- [ ] Fix `api.json` and README to advertise https rather than http, if HTTPS is enforced. Not yet confirmed: check GitHub repo Settings → Pages → "Enforce HTTPS". If it is on, change `API_URL` at the top of `_bin/build_landings_api_data.R` and regenerate `docs/api.json`. The README also still uses the old `http://openfisheries.org/api/...` URLs (see section 2).
- [ ] `docs/landings/species/AUX.json` and `CON.json` are generated by the pipeline but missing from the repo, probably because AUX and CON are reserved file names on Windows. Add them, and avoid committing generated files from Windows.

Regression check: the refactored landings pipeline reproduces the original pipeline's output byte for byte (all 2,355 landings files plus `api.json`) from `data/fishstat_export_s_capture2020.csv`. Run the unit tests from the repo root with `Rscript -e 'testthat::test_dir("tests/testthat")'` (needs testthat and withr).
